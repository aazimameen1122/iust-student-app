# IUST Student App — Download APK

**IUST Student** is an unofficial, student-developed Android app for students of the Islamic University of Science and Technology (IUST), Awantipora, Kashmir.

## Download

- **APKPure (official listing):** https://apkpure.com/iust-student/com.mussey.iustapp
- **Landing page:** https://aazimameen1122.github.io/iust-student-app/
- Version: 2.77 · Package: `com.mussey.iustapp` · Category: Education · Free

## Features

- Portal login with saved, encrypted credentials (fingerprint / screen-lock unlock)
- Automatic attendance tracking for all subjects + home-screen widget, with warnings below 75%
- Attendance history graph
- Results viewer and notices from the IUST student portal
- In-app PDF viewer, dark mode, pull-to-refresh

Credentials never leave the device. Privacy policy: https://aazimameen1122.github.io/iust-student-privacy/
